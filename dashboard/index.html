🕵️‍♂️ Rapport d'analyse : Les 5 pièges de dl.ouaisfi.eu/usba/ déjoués

1. Le Piège du DOM caché (19 modules du Niveau 1 écrasés par 15 modules du Niveau 0) :
Le code HTML servi par le serveur contient 19 modules en dur (scratchy-index.html, etagere.html, operation-milou.html, learn.html…), mais le script JS les efface immédiatement au chargement (modulesContainer.innerHTML = "") pour afficher 15 autres modules ! Solution : Les 34 modules (Niveau 0 + Niveau 1) ont été réconciliés et sont tous accessibles.
2. Le Piège du filtre « Tests » cassé (meta vs ib) :
Le menu déroulant cherche category === "meta", mais test-1.html (À réussir d'urgence) avait category: "ib" dans le JS, rendant le filtre « Tests » totalement vide (0 résultat). Solution : Catégorie normalisée + fusion avec les Méta-guides du Niveau 1.
3. Le Piège de la migration vers ouaisfieu.github.io/gemini-pro/dashboard/ :
Tous les fichiers étant en chemins relatifs (404.html, pdfs/manuel-plaidoyer-jp.pdf), héberger le dashboard sur GitHub Pages cassait tous les liens. Solution : Résolveur dynamique d'URL pointant vers https://dl.ouaisfi.eu/usba/ (Niveau 0) et https://dl.ouaisfi.eu/usba/1/ (Niveau 1).
4. Les Pièges des boutons d'annexes (capture.jpg, Rickroll & Tux) :
Le bouton ▶️ Intro (brol) (data-embed="youtubeu") prétend être un embed YouTube mais charge en réalité capture.jpg. Le bouton YouTube (exemple) est un Rickroll (dQw4w9WgXcQ). Et le bouton Pingouin pointait vers la page Wikipédia complète au lieu du SVG direct. Solution : Détection et signalement explicite + aperçu adapté.
5. Purge du script et du composant <pal-qyzvodoehdnk> injectés :
La sauvegarde HTML contenait un script tiers en en-tête et un Shadow DOM pointant vers rg-ashy.vercel.app. Solution : Code 100 % nettoyé, sémantique et optimisé SEO.
